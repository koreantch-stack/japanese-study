# 🌿 일본어 공부방

JLPT N5부터 시작해 N2까지 차근차근 공부하는 개인 학습 사이트입니다.

## 학습 원칙
- 하루 30~40분, 바쁜 날은 최소 15분
- 새 내용 70% + 복습 30%
- 듣기 연습 없이 어휘·한자, 문법, 독해, 문장 만들기, 복습 테스트 중심
- 한 번의 높은 점수만으로 급하게 다음 급수로 넘어가지 않기

## 챕터 구성
1. 일본어 이야기 5~10문장과 문장별 한국어 직역
2. 어휘·한자: 일본어, 읽기, 뜻 가리기/확인, 암기 체크
3. 핵심 문법: 의미·설명·예문과 직역
4. 직접 문장 만들기와 예시 답안 확인
5. 복습 테스트와 해설
6. 챕터 보관함, 단어장, 오답·밀린 학습, 학습 통계

## 콘텐츠 기준
현재 등록된 제22회 「가족과 함께 카레 만들기」는 2026-10-24 대화에서 확인 가능한 수업 주제와 문법을 기준으로 재구성했습니다. 기억에서 확인되지 않는 일부 문장은 N5 수준으로 보완했으므로, 예약 수업의 모든 문장을 그대로 복원한 것은 아닙니다.

## 데이터 저장
- 챕터 콘텐츠는 `lessons.json`에서 관리합니다.
- 학습 완료·오답·단어 암기 상태는 현재 브라우저의 localStorage에 저장됩니다.
- 학습 기록은 기기 간 자동 동기화되지 않습니다.
- 매일 오전 8시 예약 수업과 GitHub 자동 게시 연결은 별도 자동화 설정이 필요합니다.
