# 일본어 공부방

JLPT N5부터 N2까지 매일 한 챕터씩 공부하기 위한 학습 사이트 프로토타입입니다.

- 이야기 원문과 한국어 직역
- 어휘 및 문법 정리
- 객관식 확인 문제와 오답 기록
- 날짜별 챕터 보관함
- 브라우저 내 학습 상태 저장 및 JSON 내보내기

## 현재 상태

테스트용 예시 챕터 3개가 포함되어 있습니다. 예약학습 연동, 자동 콘텐츠 생성, GitHub Actions 자동 업데이트 및 기기 간 동기화는 아직 연결되지 않았습니다.

기존 품사 퀴즈 파일은 `index-poomsa-backup.html`에 백업했습니다.
