EP.21. 셋째 주 복습

第三週（だいさんしゅう）の復習（ふくしゅう）

EP.15부터 EP.20까지. Jay는 카페에서 주문하고, 가족에게 소포를 보내고, 동네에서 길을 묻고, 비 오는 날 우산을 사고, 회사에서 우산을 구별하고, 다나카 씨와 첫 점심을 먹었습니다. 오늘은 새 사건 대신 지난 여섯 회차의 어휘와 문법을 다시 꺼내 봅니다.

복습 전용 · 약 35분 · 읽기·어휘·문법·쓰기 중심 · 듣기 문제와 청해 연습 없음 · 이야기와 대화는 학습용 창작

STEP 1 · 이번 주 이야기 다시 읽기

각 문장 아래의 흐린 한국어 직역을 누르면 뜻이 나타납니다.

1. 土曜日（どようび）、ジェイはカフェでホットコーヒーとトーストを注文（ちゅうもん）しました。
토요일, Jay는 카페에서 핫커피와 토스트를 주문했습니다.
2. 日曜日（にちようび）の朝（あさ）、ジェイは家族（かぞく）に荷物（にもつ）を送（おく）りました。
일요일 아침, Jay는 가족에게 짐을 보냈습니다.
3. その日（ひ）の午後（ごご）、近所（きんじょ）の人（ひと）に道（みち）を聞（き）いて、駅（えき）を見（み）つけました。
그날 오후, 동네 사람에게 길을 물어서, 역을 찾았습니다.
4. 月曜日（げつようび）の夕方（ゆうがた）、雨（あめ）が降（ふ）ったので、コンビニで傘（かさ）を買（か）いました。
월요일 저녁 무렵, 비가 내렸기 때문에, 편의점에서 우산을 샀습니다.
5. 火曜日（かようび）、ジェイは傘（かさ）の持（も）ち手（て）に青（あお）いテープをつけました。
화요일, Jay는 우산의 손잡이에 파란 테이프를 붙였습니다.
6. 水曜日（すいようび）の昼（ひる）、田中（たなか）さんと食堂（しょくどう）で焼（や）き魚（ざかな）定食（ていしょく）を食（た）べました。
수요일 점심, 다나카 씨와 식당에서 구운 생선 정식을 먹었습니다.
시간 순서: EP.15 토요일 → EP.16 일요일 아침 → EP.17 일요일 오후 → EP.18 월요일 저녁 → EP.19 화요일 아침 → EP.20 수요일 점심 → 오늘은 목요일 복습일.

STEP 3 · 핵심 문법 4개

1. 주문·선택 표현: 명사 + をください / 명사 + にします

「をください」는 “~을 주세요”, 「にします」는 “~으로 하겠습니다”라는 뜻입니다. 「をください」는 가게에서 요청할 때, 「にします」는 여러 선택지 가운데 하나를 결정할 때 사용합니다. 제안 표현 「名詞（めいし）はどうですか」와도 구별하세요.

ホットコーヒーを一（ひと）つください。
직역: 핫커피를 하나 주세요.
焼（や）き魚（ざかな）定食（ていしょく）にします。
직역: 구운 생선 정식으로 하겠습니다.
焼（や）き魚（ざかな）定食（ていしょく）はどうですか。
직역: 구운 생선 정식은 어떻습니까?
2. 동사 て형 + から

의미: “~하고 나서”. 앞의 행동이 끝난 뒤 다음 행동이 이어지는 순서를 나타냅니다. 「ながら」처럼 두 행동이 동시에 진행된다는 뜻이 아닙니다.

店（みせ）を出（で）てから、傘（かさ）をさしました。
직역: 가게를 나가고 나서, 우산을 썼습니다.
3. 동사 て형 + ください / 동사 て형 + もいいですか

「てください」는 “~해 주세요”라는 부탁이고, 「てもいいですか」는 “~해도 됩니까?”라는 허가 질문입니다. 동사 て형이 같아도 말하는 목적이 다릅니다.

この機械（きかい）を使（つか）ってください。
직역: 이 기계를 사용해 주세요.
このテープを使（つか）ってもいいですか。
직역: 이 테이프를 사용해도 됩니까?
4. 동사 て형 + くれました

의미: “~해 주었습니다”. 다른 사람이 말하는 사람 또는 말하는 사람 쪽을 위해 행동했음을 나타냅니다. EP.16에서 사용한 N4 연결 표현입니다. 아직 직접 만들기 어렵다면 우선 의미를 알아보는 수준으로 복습하세요.

店員（てんいん）さんが書（か）き方（かた）を教（おし）えてくれました。
직역: 점원분이 쓰는 방법을 가르쳐 주었습니다.

STEP 4 · 생활 회화 복습

다나카 씨와 Jay가 지난 일주일을 돌아보는 학습용 창작 대화입니다.

田中（たなか）さん
この一週間（いっしゅうかん）、どうでしたか。
직역: 이 일주일, 어땠습니까?
Jay
いろいろなことがありました。カフェへ行（い）きました。
직역: 여러 가지 일이 있었습니다. 카페에 갔습니다.
田中（たなか）さん
荷物（にもつ）は送（おく）れましたか。
직역: 짐은 보낼 수 있었습니까?
Jay
はい。店員（てんいん）さんが書（か）き方（かた）を教（おし）えてくれました。
직역: 네. 점원분이 쓰는 방법을 가르쳐 주었습니다.
田中（たなか）さん
駅（えき）への道（みち）は分（わ）かりましたか。
직역: 역으로 가는 길은 알았습니까?
Jay
はい。近所（きんじょ）の人（ひと）が道（みち）を教（おし）えてくれました。
직역: 네. 동네 사람이 길을 가르쳐 주었습니다.
田中（たなか）さん
昨日（きのう）の昼（ひる）ご飯（はん）はどうでしたか。
직역: 어제 점심밥은 어땠습니까?
Jay
焼（や）き魚（ざかな）定食（ていしょく）にしました。おいしかったです。
직역: 구운 생선 정식으로 했습니다. 맛있었습니다.

STEP 5 · 헷갈리기 쉬운 표현과 오답 점검

개인별 실제 제출 답안이나 오답 기록은 이번 자료에서 확인되지 않았습니다. 아래는 이번 주 학습 내용에서 혼동하기 쉬운 표현을 골라 만든 공통 오답 점검입니다.

1. 店内（てんない）で / 持（も）ち帰（かえ）りで
매장에서 / 포장으로. 카페나 음식점에서 이용 방식을 구분합니다.
2. 送（おく）りたいです / 送（おく）ってください
보내고 싶습니다 / 보내 주세요. 자신의 희망과 상대에게 하는 부탁을 구분합니다.
3. てから / ながら
~하고 나서 / ~하면서. 행동의 순서인지 동시 진행인지 구분합니다.
4. てください / てもいいですか
~해 주세요 / ~해도 됩니까? 부탁과 허가 질문을 구분합니다.
5. てくれました / てください
~해 주었습니다 / ~해 주세요. 이미 받은 도움과 지금 하는 부탁을 구분합니다.
6. はどうですか / にします
~은 어떻습니까? / ~으로 하겠습니다. 제안과 선택 결정을 구분합니다.
7. 一（ひと）つ / 一本（いっぽん） / 一膳（いちぜん）
커피 하나 / 우산 한 자루 / 젓가락 한 벌. 물건에 따라 세는 말이 달라집니다.

STEP 6 · 상황 선택 복습 미션 6문제

미션 1. 카페에서 “핫커피 하나 주세요”라고 말하려면?
정답: A. 「음식 이름 + を一つください」는 음식이나 음료를 하나 주문할 때 사용할 수 있습니다.
미션 2. “짐을 보내고 싶습니다”에 알맞은 문장은?
정답: A. 「送（おく）る」는 보내다라는 뜻입니다. ます형 어간 「送（おく）り」에 「たいです」를 붙여 희망을 나타냅니다.
미션 3. “다음 모퉁이를 왼쪽으로 돌아 주세요”는?
정답: A. 동사 て형 + ください는 상대에게 행동을 부탁하거나 길을 안내할 때 사용합니다.
미션 4. “비가 내렸기 때문에”에 알맞은 표현은?
정답: B. 「ので」는 이유를 나타냅니다. 「てから」는 순서를 나타내므로 의미가 다릅니다.
미션 5. “이 테이프를 사용해도 됩니까?”는?
정답: C. 「てもいいですか」는 허락을 구하는 표현입니다. A는 상대에게 사용해 달라고 부탁하는 표현입니다.
미션 6. “구운 생선 정식으로 하겠습니다”는?
정답: B. 「名詞（めいし）はどうですか」는 제안이고, 「名詞にします」는 선택을 결정하는 표현입니다.

STEP 7 · 직접 문장 만들기

문제 1. “핫커피 하나 주세요.”

ホットコーヒーを一（ひと）つください。
음료 이름 뒤에 목적격 조사 「を」와 수량 「一つ」를 놓고 「ください」를 붙입니다.
문제 2. “가족에게 짐을 보내고 싶습니다.”

家族（かぞく）に荷物（にもつ）を送（おく）りたいです。
보내고 싶은 대상을 「に」로 나타내고, 「送（おく）ります」의 ます를 떼어 「たいです」를 붙입니다.
문제 3. “가게를 나가고 나서 우산을 썼습니다.”

店（みせ）を出（で）てから、傘（かさ）をさしました。
「出（で）ます」의 て형 「出（で）て」 뒤에 「から」를 붙여 순서를 나타냅니다.
문제 4. “이 테이프를 사용해도 됩니까?”

このテープを使（つか）ってもいいですか。
「使（つか）います」의 て형 「使（つか）って」에 「もいいですか」를 붙여 허가를 구합니다.
문제 5. “저는 구운 생선 정식으로 하겠습니다.”

私（わたし）は焼（や）き魚（ざかな）定食（ていしょく）にします。
선택한 메뉴 뒤에 「にします」를 붙여 결정을 나타냅니다.

STEP 8 · 이번 주 일본 생활문화 확인

  • 카페의 주문 방식은 매장마다 다를 수 있습니다. 카운터에서 먼저 주문하는 곳도 있고, 자리에 앉은 뒤 주문하는 곳도 있으므로 입구와 테이블의 안내를 확인합니다.
  • 편의점 택배는 점포와 제휴 택배사에 따라 접수 가능한 서비스와 절차가 다릅니다. EP.16은 특정 브랜드의 실제 절차를 그대로 재현한 것이 아니라 학습용으로 단순화한 장면입니다.
  • 편의점에서 투명 비닐 우산을 판매하는 경우가 있지만, 모든 점포가 같은 상품을 취급하는 것은 아닙니다. 상품과 가격은 매장에서 확인합니다.
  • 우산 손잡이에 붙이는 표시나 액세서리는 개인이 물건을 구별하기 위한 방법입니다. 모든 회사가 우산꽂이에 표시를 붙이도록 정해 둔 것은 아닙니다.
  • 일본 식당의 정식은 밥과 주된 요리, 국물이나 반찬 등을 조합한 메뉴를 가리키지만, 구체적인 구성은 가게와 메뉴마다 다릅니다.
